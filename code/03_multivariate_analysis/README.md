# Multivariate analysis (多变量分析 / MVPA)

**Steps 18–41**, grouped by actual work:

- Single-trial GLM: HRF, nuisance regressors, high-pass/AR(1), design QC, trial beta maps and labels
- Searchlight: valid-voxel/center masks, trial-wise features, train/test splitting, linear SVM, group maps, permutations
- ROI: atlas-defined ROIs, within-format and cross-format decoding, tests for each comparison, sample matching
- RSA: average action patterns, RDM construction, within- and cross-format comparison, repeated trial matching
- Statistical testing and visualization belong with the corresponding analysis here

**There is no separate shared statistics folder.** Keep original and matched-data inference distinguishable; document permutation schemes and correction families from the real code.
