# Univariate analysis 

**Steps 14–17**, plus other univariate analysis **only when confirmed in actual code**:

- Condition-level / first-level GLM: specify and estimate action-condition effects
- Contrast computation, including the documented `All_actions > baseline`
- Second-level group analysis, including the documented one-sample t-test
- Statistical inference and multiple-comparison correction, including FWE
- Additional verified contrasts, model checks and visualization can live in this same folder

**All univariate statistics belong in this folder**, not in a separate shared statistics directory.

This is the conventional GLM branch. Do not mix it up with the individual-trial GLM that supplies beta images to classification.
